# Finance Platform — React

Primeiro estágio da plataforma de organização, análise e planejamento financeiro pessoal.

## Escopo atual

- Dashboard desktop-first baseado na referência visual enviada.
- Sidebar responsiva.
- Cards de saldo, receitas, despesas e economia.
- Gráfico de evolução financeira.
- Gastos por categoria.
- Insight financeiro.
- Transações recentes.
- Orçamento e metas resumidos.
- Modal funcional para novo lançamento (UI).
- Rotas-base para as demais áreas.

## Próxima etapa

Implementar os módulos de domínio:
1. CRUD de transações
2. categorias e contas
3. orçamento
4. metas
5. cartões e faturas manuais
6. análises
7. autenticação e persistência

## Executar

```bash
npm install
npm run dev
```
